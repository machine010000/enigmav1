# Shared Intelligence

Shared Intelligence domains are reusable expertise areas that all business modules consume. They represent Enigma's collective knowledge across different domains.

## Philosophy

Shared Intelligence follows these principles:

1. **Single Source of Truth**: Each domain has one authoritative implementation
2. **Governance Required**: All domain knowledge must pass through Knowledge Governance
3. **Cross-Module Usage**: All modules can consume any domain
4. **Continuous Learning**: Domains improve through evidence and research
5. **Immutable History**: All domain changes are versioned and traceable

## Domain Architecture

```
Shared Intelligence Layer
  ↓
Intelligence Domains
  ↓
Knowledge Governance
  ↓
Knowledge Graph
  ↓
Cognitive Core (consumes)
```

## Core Intelligence Domains

#### Purpose

Provides expertise in search engine optimization, keyword research, technical SEO, and content optimization.

#### Why Shared

SEO is required across:
- **Seller**: SEO audit jobs, content writing jobs
- **Content Creator**: Content optimization, keyword targeting
- **Service Provider**: SEO service offerings

#### Capabilities

- **Keyword Research**: Discover and analyze keywords
- **Technical SEO**: Audit and fix technical issues
- **On-Page SEO**: Optimize page content
- **Off-Page SEO**: Build backlinks and authority
- **Local SEO**: Optimize for local search
- **SEO Analytics**: Track and measure SEO performance

#### Knowledge Areas

- Search engine algorithms
- Ranking factors
- Keyword difficulty
- Technical requirements
- Best practices
- Tool proficiency (Ahrefs, SEMrush, etc.)

#### How Modules Consume

**Seller Module**:
- Evaluates SEO job requirements
- Generates SEO audit proposals
- Executes SEO tasks
- Captures SEO execution evidence

**Content Creator Module**:
- Optimizes content for SEO
- Researches keywords for content
- Measures content SEO performance
- Improves content based on SEO data

**Service Provider Module**:
- Packages SEO services
- Delivers SEO to clients
- Measures SEO service outcomes
- Improves SEO service offerings

#### How Master Brain Uses

Master Brain uses SEO Intelligence for:
- **Context Building**: Understanding SEO requirements in goals
- **Gap Analysis**: Identifying missing SEO knowledge
- **Planning**: Creating SEO execution plans
- **Decision Making**: Deciding on SEO strategies

#### Ownership Boundaries

- **Owned By**: Academy (curriculum and lessons)
- **Maintained By**: Research (new SEO knowledge)
- **Governed By**: Knowledge Governance (validation)
- **Consumed By**: All modules (through cognitive core)

## Domain Integration

### Cross-Domain Usage

Domains often work together:

- **SEO + Copywriting**: SEO-optimized content
- **Psychology + Copywriting**: Persuasive copy
- **Analytics + Marketing**: Data-driven marketing
- **Branding + Psychology**: Brand psychology
- **Research + All**: Evidence-based decisions

### Domain Evolution

Domains evolve through:

1. **Research**: New research adds to domain knowledge
2. **Evidence**: Execution evidence validates domain knowledge
3. **Governance**: Knowledge governance matures domain knowledge
4. **Academy**: Academy teaches domain knowledge
5. **Application**: Modules apply domain knowledge

### Domain Maturity

Each domain has maturity levels:

- **Level 0**: Unknown
- **Level 1**: Definition
- **Level 2**: Multiple Sources
- **Level 3**: Applied
- **Level 4**: Validated
- **Level 5**: Expert Knowledge
